Topic categories (Atlas, Topic lens, depth 1)

Drawn on the rim of each top-level circle in the circle-pack, 18px in the category's own green. A new family beside the rail and status icons: same Phosphor grammar, no shared frame. Four are visible with the cached catalogue; the live catalogue can show all eleven.

Open decisions

  1. Topic lens only, or also the Space lens (Point / Line / Polygon / Raster / Non-spatial), which maps naturally to icons?
  2. Mobility as tram (Basel-specific) or bicycle (the running/cycling use cases)?
  3. Subcategories (≈40) stay without icons: at that depth icons would be decoration, not recognition. Agreed?
